## Two traps this block records so nobody re-derives them

1. **A dev-server page fires every request TWICE.** Next 16 defaults `reactStrictMode` on, so
   every effect double-invokes — including the shell's own `/api/admin/notifications`. Judge the
   **shape** of the calls, never the count. (`P23341`-family, and `P08313` updated in place.)
2. **Route interception is defeated by the service worker.** A Playwright `page.route` handler
   does not see a request the app's own service worker answers, so a "make this feed fail" test
   renders real data and comes back green. Every fault-injection page in this run was opened with
   `serviceWorkers: "block"`. Without it, five of the checks below were falsely green on the
   first attempt.
