a `read the shipped file · <expression>` row is a text assertion against the file named in it; a
`headless on YOUR OWN port · <expression>` row is that expression evaluated inside the live panel's frame
(sign in with `scripts/sweep/login.mjs` → `loginAs(ctx, "manager", base)`, open `/manager`, wait for
`#editor`, then evaluate). The five fixes this sweep made are additionally guarded for good by
`npm run verify:panel-scope` (new) and section **H** of `npm run verify:manager-behaviour`.

this branch; the rows that were red on pass 1 say so in their note.
