```sh

```

One login per role for the whole run, cached to disk across processes, because staff login is limited
to five in five minutes and tripping it alerts the owner's phone about his own tooling. Every row
written is deleted **by its own id**, and every setting flipped is restored **and verified back**, in
a `finally` and on SIGINT.

## What this round found

Four faults, every one of them fixed in the same branch:

1. **A day sheet for a finished day could serve the first hour of it as the whole day.** Measured:
   2026-09-09 served **1.1h**, forced fresh **24.0h**. The cache key was the day's START only, so an
   in-progress day and a finished one shared it — and the change-detector watched the same truncated
   window, so it could never notice the rest of the day.
2. **Nine id-shaped parameters answered a malformed value with a retryable 503.** "Please try again"
   for a retry that can never succeed — and the project's own rule queues a 5xx like offline.
3. **A page past the end of the Activity log and the Removals record answered 503.** PostgREST's
   PGRST103 went straight into `dbFail`. 554 rows, `pages: 3`, and page 4 → a red error.
4. **Round 1's own fifty rows named no file**, so rule 2b's measurement read `lib/aggregators.ts` as
   having zero rows when it had twenty-one — the exact failure that rule exists to prevent.

## Five of these checks were wrong before they were right, and sabotage is what found it

Recorded because a check that passes for the wrong reason is worse than no check:

- `&&` returns its last operand, so 105 checks reported a timestamp as their failure reason.
- The comment stripper ran block comments first, and the header line `// … for /api/owner/*.`
  opened a fake block comment that swallowed 1,800 characters including the type being asserted.
- Cache stamps were compared as STRINGS — a fresh compute answers `…Z`, the stored row
  `…+00:00` — so the first open of every key reported a cache miss.
- Two money checks compared snapshots taken minutes apart on a database other terminals are trading
  on, and called concurrent revenue a disagreement.
- One check hard-coded a phone number "nobody has". Somebody had it.

**Result key:** ✅ pass · ❌ fail · ⏭ skipped, with a written reason.
