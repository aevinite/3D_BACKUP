Each fix is asserted by the **rule** it broke, not by the shape of the patch — a guard pinned to a
code shape goes red for a refactor and green for the fault returning a different way. The
identity-actions check harvests every action name the app writes and fails if any login/password/
pin/profile one is missing from the set, which is how it caught `login_denied` and `login_blocked`
after the eye had found only `login_failed`.

## Two things a dev server cannot answer, and the guard says so instead of lying

- **Request counts.** React StrictMode double-invokes every effect under `next dev`, so a page that
  fetches once in production fetches twice here. Measured 2026-09-04: `verify:owner-s7-live`
  reports **197/3** against `localhost:4315` and **200/0** against the deployed build, on identical
  code. The three failures are the dev server, not the product — and the new live guard SKIPS those
  checks with that sentence rather than reporting a fault that does not exist.
- **Tap targets on Audit & logs.** Measurable, and measured — but the fix is in another lane's file,
  so the guard prints the numbers as a ⏭ every run rather than going permanently red. A guard that
  cries wolf is how a suite stops being read; this project has the scar.

## One check that nearly became an invented fault, and how it was caught

**P69062–P69063.** The roster's completeness number comes from `completeness(u)` with no options
(14 checks) while the profile passes `{ pay: … }` (13 when the payroll module is off) — which reads
exactly like "two screens, one person, two numbers", and would have been filed as a regression
against **T13 P06444**. It is not one. The roster only renders a bar when `eligible`, which requires
the same module flag the profile's `pay` reads, and the roster carries no owner row — checked
against the live data: 7 rows with a number, 4 without, all four kitchen. So the two cannot disagree
on any screen a person can reach today. **P06444 stays ✅.** What is true is that the roster is
correct by *coincidence* rather than by construction, which is carried into the report as a
hardening item and nothing more.
