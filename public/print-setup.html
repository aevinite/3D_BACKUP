1 · Start here — the short version

  1. Plug the printer in and print one test page from the computer itself Make that printer the computer's default printer first — automatic printing always goes to the default. If the test page looks like a normal shop receipt, the printer half is already finished: you do not have to set any paper options at all. Each menu below only sends you to its settings table if the test came out wrong.
  2. Pick your computer’s menu — ① Windows, ② Mac or ③ Linux / Raspberry Pi — and follow it once. Each menu walks you through making one small file yourself: open the text editor, press Copy on the code, paste it, save it with the exact name. There is nothing to download, and that is deliberate — a downloaded script is blocked by macOS (“Apple could not verify…”) and warned about by Windows, while a file you typed yourself simply opens.
  3. Ask us to switch printing on for the restaurant, and to say whether tickets print on the kitchen screen or the counter screen. (the switches)
  4. On that computer, say “print here” — kitchen screen: ☰ → Settings → 🖨 Printing; counter screen: Settings → Printing, or the strip that appears above the Tables grid.
  5. Send one order. A ticket should come out in a few seconds.
  6. Now minimise that window and send another. It must still print. That second ticket is the whole point of this setup. (the test)
In simple words: plug the printer in, print one test from the computer to see it works, open one special window on that computer, tell the app that this screen is the printer, then check it still prints when the window is hidden. The long tables of settings are only for when something looked wrong — they are a repair kit, not a checklist.

1b · The best way now: let a computer print, not a screen new

Nothing has to stay open any more. A tiny program — we call it the helper — sits on the computer your printers are plugged into. Every two seconds it asks the app "anything to print?", and prints whatever comes back on the right printer. No window, no login, nothing to keep in front, nothing anybody can close by accident.

How to set it up — four steps

  1. Ask us to add your computer. We do it on our side in seconds and hand you a block of text with a Copy button — it already has your site address and your computer's own code inside it. You are given the text, never a file to download, because a downloaded script is what macOS and Windows block.
  2. Make the file yourself — the same way as the starter file in your own menu below: Notepad on Windows (Save as type: All Files), TextEdit on a Mac (Format → Make Plain Text), or nano on Linux. Save it with the exact name we give you.
  3. Double-click it once. Nothing appears on screen — that is correct. It is now telling the app which printers this computer has, and they show up on our side straight away.
  4. Tell us which printer prints what — kitchen slips, bills, banquet sheets. We set those three lines, and paper starts coming out. Change your mind any time; it takes effect on the next couple of seconds, with nothing to reinstall.

What you will see once it is running

  • Your kitchen screen's 🖨 sheet says "Tickets print on: <your printer> — from <your computer>", and says so plainly if that computer has gone to sleep.
  • Your manager screen stops asking "should this screen print?" — a program is doing it.
  • Pressing Print on a bill opens no window at all: you get a line saying which printer it went to.
If that computer is off, nothing is lost. Tickets wait in the app and print in order the moment it is back — never twice, never in the wrong order. And you can name a backup printer for each kind of paper, which takes over if the first prints nothing for a minute.
Still want the old way? It has not gone anywhere. A restaurant that installs nothing keeps printing exactly as this guide's own menus describe — one screen volunteers, and the app uses it. The helper is the better path, not the only one.

2 · Why printing used to stop (worth 60 seconds)

Kitchen tickets used to be printed by whichever screen happened to notice a new order. That only works while that screen is the window you are looking at. Minimise it — or simply open any other app on top of it — and the browser put it to sleep, so printing stopped completely, with nothing anywhere saying so.

Now the order itself leaves a “print me” job on our server. One screen is the printer; it takes each job, prints it, and tells the server it is done. If no screen takes it, the job waits — it can no longer be lost — and after 90 seconds the manager's Tables screen shows a warning with a 🖨 Print here instead button.

What this means for you: the printing window can be minimised, covered, or on another desktop, and tickets still come out. If the computer is off, the tickets are waiting the moment it comes back on.

The little file you make in your own menu below is the second half: it opens Chrome with the specific settings that stop it dozing off behind other windows, and keeps the computer itself awake.

The computer

Any Windows PC, Mac, Linux box or Raspberry Pi already there is fine — it does not need to be fast. It needs three things: it stays on during service, it is on the internet, and the printer is plugged into it (or reachable on the same network).

Paper

Thermal rolls to match your printer — 80 mm is the usual kitchen size, 58 mm is the narrow card-machine size. Keep two spare. Thermal paper has no ink at all: if nothing prints, the roll is either finished or in upside down (the printing side is the one that goes grey when you scratch it).

4 · ① Windows — every step Windows 10 / 11

Nothing to download. You will type (paste) one small file yourself in Notepad. Windows never shows the “Windows protected your PC” warning for a file you made on your own computer — that warning only ever appears on files that came off the internet.
Do I have to type in all the settings? No. Most printers print perfectly the moment Windows sees them. Steps 4.1 and 4.2 are the whole job for nine printers out of ten. 4.3 is a repair kit, not a checklist — open it only if your test ticket came out wrong.

4.1 · Plug it in and let Windows find it

  1. Put the paper in the right way round. Thermal paper only prints on one side. If the roll is in upside down you get blank paper for ever and think the printer is broken. Pull a little out, scratch it with a fingernail — the side that goes grey is the printing side, and it must face the little glass bar inside.
  2. Plug the USB cable straight into the computer — not through a hub if you can help it — and switch the printer on.
  3. Open the printer list: Settings → Bluetooth & devices → Printers & scanners.
  4. Look for your printer's name in that list.
    · It is there → Windows already knows it. Go to 4.2.
    · It is not there → it needs a driver. Go to 4.4, then come back here.
In simple words: paper in the right way round, cable in, switch on, and check the computer can see it. A driver is just the small translator that teaches a computer to talk to one exact printer model — Windows carries thousands of them and usually finds the right one alone.

4.2 · The first test — and the two things you must set

  1. Print a test page. Click your printer in that list → Manage → Print test page. If Windows itself can't print, the app certainly can't — so this comes first, always.
  2. Make it the default printer. Same screen → Set as default. Automatic printing always goes to whatever the computer calls its default printer.
  3. Turn OFF “Let Windows manage my default printer” (top of the Printers & scanners screen). Leave it on and Windows quietly makes the last-used printer the default — a week later tickets are going to the office printer and nobody knows why.
  4. Now look at the paper that came out and answer one question: does it look like a normal shop receipt?
    · Yes — clean lines, the right way up, cut at the end → you are finished with printer settings. Skip 4.3 entirely and go to 4.4.
    · No → 4.3 has one row for each thing that can look wrong.

4.3 · Only if the test came out wrong — one fix each skip if it looked fine

Everything here is done in one place: Printers & scanners → your printer → Printer properties → Preferences. No typing, no commands — just find the setting named in the middle column. Words differ between makes; the middle column gives the usual spellings.

What the paper looked likeThe setting to look forSet it to
A big blank gap before each ticket, or one ticket per huge sheet Paper size (Preferences → Paper/Quality) The receipt size — a name with your roll's width in it, like 80(72.1)mm × Receipt or 80mm × 297mm. Never A4.
Sideways, or shrunk to half size Orientation / Scaling / Fit to page Orientation Portrait, scaling 100% or “none”. A page shaped wrongly is what makes a printer turn the ticket on its side.
The right-hand edge of every line is missing Paper width / Paper size Check the roll really is 80 mm and that the size chosen says the same. A 58 mm roll with an 80 mm setting always loses its right edge.
It cuts through the middle of the ticket Cut / Cutter / Paper cut After the job (not “after each page”) — the cut must happen after the paper has been fed out, or the blade lands in the middle of your ticket.
It never cuts at allCutter Turn it on — if your model has a blade. Many cheap ones don't; then you tear it off, and that is normal.
Nothing comes out at all— Roll in upside down (4.1), printer not the default (4.2), or the cable is too long — USB is only good for about 5 m.
Never set a paper size inside the app. The app deliberately sends the ticket with no page size of its own so that your printer's own paper setting wins. Forcing a size in the app is what produces sideways tickets and 20 cm of blank paper.

4.4 · If Windows didn't find your printer — getting the driver

  1. Search the exact model plus the word driver. The model is printed on the label under or behind the printer — for example XP-80C driver, TVS RP 3200 driver, Epson TM-T82 driver. Use the maker's own website.
  2. Install it, then unplug and replug the printer. Windows now names it properly in Printers & scanners.
  3. Still nothing? There is often a driver CD in the box, and cheap 80 mm printers are nearly all clones of the same design — a driver named POS-80, ZJ-80 or XP-80 usually drives them all. Try one of those.

4.5 · Make the print-station file — every click

This one file opens Chrome with the settings that make tickets print by themselves and stop the window dozing off when it is minimised or covered.

  1. Open Notepad. Press Start, type notepad, press Enter.
  2. Copy the code below. Press the Copy button in the top-right corner of the black box — don't retype it by hand, a single missing word stops the automatic printing.
  3. Paste it into Notepad — click inside the Notepad window and press Ctrl + V.
  4. File → Save As…
  5. Choose Desktop in the left-hand list, so the file is easy to find.
  6. Change “Save as type” from Text Documents (*.txt) to All Files (*.*). This step matters most. Skip it and Windows saves print-station.bat.txt, which does absolutely nothing when double-clicked — and nothing tells you why.
  7. Name it and save it. In File name type exactly print-station.bat, press Save, then close Notepad.
  8. Check the name. On the Desktop the file must read print-station.bat. If it reads print-station.bat.txt, right-click → Rename and remove the .txt. (If you can't see the ending: File Explorer → View → Show → File name extensions.)

The code — press Copy, then paste it into Notepad exactly as it is:

@echo off
set "URL=https://www.aevinite.shop/kitchen"
set "PROFILE=%LOCALAPPDATA%\AevidinePrintStation"

set "CHROME=%ProgramFiles%\Google\Chrome\Application\chrome.exe"
if not exist "%CHROME%" set "CHROME=%ProgramFiles(x86)%\Google\Chrome\Application\chrome.exe"
if not exist "%CHROME%" (
  echo Install Google Chrome first, then run this again.
  pause
  exit /b 1
)

powercfg /change standby-timeout-ac 0 >nul 2>&1
powercfg /change monitor-timeout-ac 0 >nul 2>&1

start "" "%CHROME%" --kiosk --kiosk-printing ^
 --user-data-dir="%PROFILE%" ^
 --disable-background-timer-throttling ^
 --disable-backgrounding-occluded-windows ^
 --disable-renderer-backgrounding ^
 --disable-features=CalculateNativeWinOcclusion ^
 --no-first-run --no-default-browser-check ^
 --autoplay-policy=no-user-gesture-required ^
 "%URL%"
The only line you may ever want to change is the second one — set "URL=…". It already says your own address, https://www.aevinite.shop. Keep /kitchen at the end for a screen in or near the kitchen, or change it to /manager for the counter screen. Nothing else in the file ever needs touching.

4.6 · Start it and log in — once

  1. Double-click print-station.bat on the Desktop. A black box flashes, then a Chrome window opens full-screen with no address bar. That full-screen window is normal: it is what stops anyone browsing on the printing computer.
  2. Log in with the kitchen (or manager) username and password. You only do this once — this window keeps its own separate Chrome profile, so it stays logged in for good and your normal Chrome is left completely untouched.
Nothing happens when you double-click? The file is almost certainly saved as print-station.bat.txt — go back to step 4.5.8.

4.7 · Tell the app that THIS screen is the printer

  1. Ask us to switch printing on for your restaurant, and to say whether tickets come out on the kitchen screen or the counter screen. That is one switch on our side (§8).
  2. On this computer: kitchen screen → ☰ → Settings → 🖨 Printing → Print here. Counter screen → Settings → Printing, or the strip that appears above the Tables grid.
  3. Send one order and watch a ticket come out. Then do the real test.

4.8 · Make it start by itself (strongly recommended)

  1. Right-click print-station.bat → Show more options → Create shortcut.
  2. Open the Startup folder. Press Win + R, type shell:startup, press Enter — a folder opens.
  3. Drag the shortcut into that folder.

From now on the print station opens whenever the PC starts — including after a power cut, before anyone has to remember.

To finish for the day: press Alt + F4 in the Chrome window.

5 · ② Mac — every step macOS

Nothing to download — on purpose. macOS blocks any script that came from the web: double-clicking one gives “Not Opened — Apple could not verify it is free of malware” with only Done or Move to Bin, and the old right-click → Open way out was removed in macOS Sequoia. Nothing is wrong with such a file — but a file you type on your own Mac never gets that flag in the first place, so it simply opens. Everything below is typed by you.
Do I have to type in all those settings? No. If the test ticket in 5.2 looks like a normal shop receipt, you are done — skip 5.3 and 5.4 completely. They are a repair kit for a ticket that came out wrong, not a list everybody has to work through.

5.1 · Plug it in and let the Mac find it

  1. Put the paper in the right way round. Thermal paper prints on one side only. Pull a bit out and scratch it with a fingernail: the side that goes grey is the printing side, and it must face the little glass bar inside the printer. A roll in upside down gives blank paper for ever — and looks exactly like a broken printer.
  2. Plug the USB cable straight into the Mac (not through a hub if you can avoid it) and switch the printer on.
  3. Open the printer list. Apple menu  → System Settings → Printers & Scanners.
  4. Is your printer in the list?
    · Yes → go to 5.2. The Mac already knows it.
    · No → press Add Printer, Scanner or Fax… (+), pick your printer, and see what the Use menu offers. If it names your printer or something like ZJ-80 / POS-80 / Generic Thermal, choose that, name it Kitchen, press Add, and go to 5.2. If the Use menu has nothing but Generic PostScript Printer, go to 5.4 first.
Never accept “Generic PostScript Printer”. PostScript is a language big office printers speak and receipt printers do not. Choose it and the very first print comes out wrong or as pages of gibberish — for that reason alone.
In simple words: a driver is the little translator that teaches your Mac to talk to one exact printer model. Big brands supply one. The cheap 80 mm printers often don't, which is what 5.4 is for.

5.2 · The first test — and the one thing you must set

  1. Make it the default printer. In Printers & Scanners, set Default printer to your printer. Automatic printing always goes to the default — this one setting is not optional.
  2. Print anything. Open TextEdit, type the word hello, press ⌘P, choose your printer, press Print. If the Mac itself can't print, the app can't either, so always start here.
  3. Look at the paper and answer one question — does it look like a normal shop receipt?
    · Yes: upright, clean, cut or torn off at the end → finished with printer settings. Skip 5.3 and 5.4 and go to 5.5.
    · No → 5.3 has one row for each way it can look wrong.

5.3 · Only if the test came out wrong — one fix each skip if it looked fine

You can do all of this by clicking, no commands needed. Open Safari or Chrome and go to http://localhost:631/printers — that page is your Mac's own printer control panel, already installed, no internet needed. Click your printer, then Administration → Set Default Options. Everything in the middle column below is on that page.

What the paper looked likeThe setting to look forSet it to
A big blank gap before each ticket (sometimes 20 cm of nothing) Media Size / Page Size The shortest receipt size in the list whose width matches your roll — names look like X70MMY65MM or 80x297mm. Never A4 or Letter.
Sideways, or shrunk to about half size Media Size again Same as above. A page that is a different shape from the roll is exactly what makes the driver rotate the ticket and shrink it to fit.
The right-hand edge of every line is missing Media Size (its width part) Check the roll really is 80 mm and that the size you picked says the same width.
It cuts through the middle of the ticket Cut Media / Cutter End of Job — not “end of page”. The blade must fall after the paper has been fed out.
It never cuts, or the ticket won't clear the tear bar Feed Where / Feed Distance / Cutter Feed after the job, distance about 30 mm, cutter on if your model has a blade. Plenty of cheap ones have none — then you tear it off, which is normal.
Nothing at all— Roll upside down (5.1), not the default printer (5.2), or a USB cable over about 5 m.

The same thing typed, if you prefer

Two commands. The first one asks your printer what it can do — it is safe, it changes nothing, and it prints a list where every line is one setting and the * marks what is in use right now. The second one sets the ones you chose from that list. Open Terminal (⌘ + Space, type terminal, Enter):

lpoptions -p "Kitchen" -l
lpadmin -p "Kitchen" \
  -o PageSize=PUT-A-SIZE-FROM-YOUR-OWN-LIST-HERE \
  -o CutMedia=EndOfJob \
  -o FeedWhere=AfterJob
Type only the settings your own list showed. Copying a setting name from someone else's printer is the usual way to get “Unknown option” — every make spells them differently, which is exactly why the first command exists.
Never set a paper size inside the app. The app sends the ticket with no page size of its own, on purpose, so that your printer's paper setting wins. Forcing a size in the app is what produces sideways tickets and long blank lead-ins.

5.4 · If the Mac has no driver for your printer

Work down this list and stop at the first one that works.

  1. The maker's website. Search the exact model from the label under the printer plus driver mac — Epson TM-T82 driver mac, Star TSP100 driver mac. Every brand-name printer has one, it installs by double-clicking, and then your printer appears in the Use menu in 5.1. Try this first — it needs no Terminal at all.
  2. The free community driver, for the cheap unbranded 80 mm printers (sold as POS-80, ZJ-80, XP-80, Zjiang and a dozen other names — they are nearly all the same machine inside). Open Terminal and paste these lines one at a time, pressing Enter after each: 
    xcode-select --install

    That one may open a small Apple installer — let it finish, it is Apple's own free developer tools and the next line needs them. If it says “already installed”, carry on.

    cd ~/Downloads
git clone https://github.com/klirichek/zj-58
cd zj-58
make
sudo cp rastertozj /usr/libexec/cups/filter/
sudo cp zj80.ppd /Library/Printers/PPDs/Contents/Resources/

    In plain words, line by line: go to your Downloads folder · fetch the driver · step into it · build it · put its two pieces where macOS looks for drivers. The two sudo lines will ask for your Mac password — typing it shows nothing on screen, which is normal. Then go back to 5.1, add the printer again, and pick ZJ-80 in the Use menu.

  3. If neither works, your model may simply never have had a Mac driver — that happens, and it is not your fault or the printer's. The same printer will work from a Windows PC (§4) or a Raspberry Pi (§6), and either of those makes a better print station anyway because it can be left switched on.

5.5 · The 30-second way — one line in Terminal, no file at all try this first

  1. Open Terminal. Press ⌘ + Space, type terminal, press Enter.

5.6 · The every-day way — make the file yourself, every click

  1. Open TextEdit. Press ⌘ + Space, type textedit, press Enter. Choose New Document if it asks.
  2. Format → Make Plain Text (or ⇧⌘T). This step matters most. TextEdit writes decorated “rich text” by default and a rich-text file will never run — it just opens in TextEdit again, and nothing tells you why.
  3. Copy the code below. Use its Copy button, click into TextEdit, press ⌘ + V.
  4. File → Save… Press ⌘ + Shift + D to jump to the Desktop, or pick Desktop in the sidebar.
  5. Name it and save it. In Save As type exactly print-station.command. If a box asks about the ending, choose Use .command. Then close TextEdit.
  6. Make it runnable. In Terminal, paste these two lines and press Enter: 
    chmod +x ~/Desktop/print-station.command
~/Desktop/print-station.command
    The first line gives the file permission to run; the second starts it right away.
  7. Log in once in the Chrome window that opens. It keeps its own Chrome profile, so it stays logged in and your normal Chrome is untouched.
  8. From now on, just double-click it. Because you typed this file yourself it carries no download flag, so macOS never shows the “could not verify” message for it.

The code — press Copy, then paste it into plain-text TextEdit:

#!/bin/zsh
URL="https://www.aevinite.shop/kitchen"
PROFILE="$HOME/.aevidine-print-station"
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"

if [ ! -x "$CHROME" ]; then
  echo "Install Google Chrome first, then run this again."
  read -r "?Press return to close…"
  exit 1
fi

"$CHROME" \
  --kiosk --kiosk-printing \
  --user-data-dir="$PROFILE" \
  --disable-background-timer-throttling \
  --disable-backgrounding-occluded-windows \
  --disable-renderer-backgrounding \
  --no-first-run --no-default-browser-check \
  --autoplay-policy=no-user-gesture-required \
  "$URL" &
CHROME_PID=$!
caffeinate -dimsu -w $CHROME_PID &
wait $CHROME_PID
The only line you may ever want to change is the second one — URL="…". It already says your own address, https://www.aevinite.shop; keep /kitchen for a kitchen screen or put /manager for the counter. Nothing else needs touching.

5.9 · Already got a downloaded starter file sitting in Downloads?

Older versions of this guide offered one to download, and that is the file that shows “Apple could not verify…” (a macOS protection called Gatekeeper). You don't need it — 5.4 above replaces it — but if you'd rather use it, either of these gets you past it:

bash ~/Downloads/print-station-mac.command

6 · ③ Linux & Raspberry Pi — every step Ubuntu · Debian · Raspberry Pi OS

The cheapest print station that nobody ever touches: a Raspberry Pi (₹4,000–5,000) behind the till, 3 watts, no fan to clog with kitchen grease, and it comes back by itself after a power cut.

Nothing to download here either. You type the file with nano, the plain text editor that is already on the machine.
Do I have to set all the paper options? No. Add the printer, print one test, and if it looks like a shop receipt you are done. 6.3 is the repair kit for a ticket that came out wrong — most people never open it.

6.1 · Plug it in and add it

  1. Paper the right way round — thermal paper prints on one side only. Scratch it: the side that turns grey faces the glass bar inside.
  2. Install the printing system (once per machine), then let your user manage printers: 
    sudo apt update && sudo apt install -y cups
sudo usermod -aG lpadmin $USER
    Log out and back in after that second line, or it won't take effect yet.
  3. The easy way — by clicking. Open a browser on that machine and go to http://localhost:631/admin. That is your own printing control panel, already installed, no internet needed. Press Add Printer, choose your USB printer, and give it the name Kitchen. If the driver list has nothing for your model, choose Raw — see the note in 6.3.
  4. Or by typing, if you prefer. The first line asks the machine what printers it can see and prints their addresses; put the address it shows into the second line: 
    lpinfo -v
sudo lpadmin -p "Kitchen" -E -v "PUT-THE-ADDRESS-FROM-THE-LINE-ABOVE" -m raw
lpoptions -d "Kitchen"
    The last line makes it the default printer, which automatic printing always uses.
  5. A network printer instead of USB (the best choice on a Pi): give the printer a fixed address in your router first — otherwise it moves house one day and printing stops for no visible reason — then: 
    sudo lpadmin -p "Kitchen" -E -v socket://192.168.1.50:9100 -m raw

6.2 · The first test

  1. Print something: 
    echo "hello" | lp -d "Kitchen"
  2. Look at the paper. Like a shop receipt → done, skip 6.3. Wrong in some way → 6.3.

What “Raw” means, in plain words: it tells the printing system to pass the job straight through without translating it. For many cheap thermal printers that is exactly right and needs no driver at all. 6.4 · Make the print-station file — every step

  1. Open a Terminal. Type nano ~/print-station.sh and press Enter — an empty editor fills the window.
  2. Copy the code below. Use its Copy button — never retype a command line by hand.
  3. Paste it into nano. Press Ctrl + Shift + V, or right-click → Paste.
  4. Save and leave. Press Ctrl + O then Enter to save; Ctrl + X to leave.
  5. Make it runnable and start it: 
    chmod +x ~/print-station.sh
~/print-station.sh
  6. Log in once in the Chrome/Chromium window that opens.
#!/bin/sh
URL="https://www.aevinite.shop/kitchen"
PROFILE="$HOME/.aevidine-print-station"

BROWSER=""
for b in chromium-browser chromium google-chrome google-chrome-stable; do
  command -v "$b" >/dev/null 2>&1 && { BROWSER="$b"; break; }
done
[ -z "$BROWSER" ] && { echo "Install Chromium:  sudo apt install -y chromium-browser"; exit 1; }

xset s off 2>/dev/null; xset -dpms 2>/dev/null; xset s noblank 2>/dev/null

exec "$BROWSER" \
  --kiosk --kiosk-printing \
  --user-data-dir="$PROFILE" \
  --disable-background-timer-throttling \
  --disable-backgrounding-occluded-windows \
  --disable-renderer-backgrounding \
  --no-first-run --no-default-browser-check \
  --autoplay-policy=no-user-gesture-required \
  "$URL"
The only line you may ever want to change is the second one — URL="…" — already your own address, https://www.aevinite.shop, plus /kitchen or /manager.

6.5 · Tell the app that THIS screen is the printer

  1. Ask us to switch printing on. We also set whether tickets come out in the kitchen or at the counter (§8).
  2. On this machine: kitchen screen → ☰ → Settings → 🖨 Printing → Print here. Counter screen → Settings → Printing.
  3. Send one order. A ticket should come out in a few seconds — then do the real test.

6.6 · Start on boot (what makes it maintenance-free)

mkdir -p ~/.config/autostart
cat > ~/.config/autostart/print-station.desktop <<EOF
[Desktop Entry]
Type=Application
Name=Aevidine print station
Exec=$HOME/print-station.sh
X-GNOME-Autostart-enabled=true
EOF
After a power cut the Pi boots, opens the window and prints again — with nobody touching it. That is the one thing a PC at the till never does.

10 · The test that actually matters

  1. Send a real order from the waiter tablet or the guest menu to a test table. A ticket should come out within a few seconds.
  2. Now minimise the print window — or open any other app full screen on top of it. This is exactly what used to kill printing.
  3. Send a second order. It must print while the window is still hidden. That is the test.
  4. Close the print window completely and send a third. Nothing prints — correct. Re-open the print station: the missed ticket comes out straight away. Nothing was lost.
  5. Cancel your test orders (manager → the table → cancel) so they never reach a real bill.
In simple words: print one, hide the window and print another, then close everything and prove the missed ticket appears when you re-open. That covers every way it used to fail.

Testing without wasting paper

Install a PDF printer and make it the default while you test — every “print” becomes a file you can look at. Windows already has Microsoft Print to PDF; a Mac's print dialog has Save as PDF; on Linux sudo apt install printer-driver-cups-pdf. Set the real printer back as default when you are done.

11 · Every setting explained

The printer's own settings — what each one actually does

These live on the printer, not in the app, and every make spells them differently. That is why this page never tells you to paste a fixed list: ask your own printer what it has (§5.3 · §6.3), or read them off the driver window on Windows (§4.3), and set only what is there.

Called something likeIn plain words
Paper size · Media Size · PageSize How wide the paper is and how long one “page” is. A receipt roll wants a narrow, short size — width matching your roll (80 mm). Choosing A4 is the single most common mistake: the printer then waits for an A4-sized page, which is where a long blank lead-in and a sideways ticket both come from.
Cut · Cut Media · Cutter When the blade cuts, if your printer has one. It must cut after the whole job. “After each page” cuts before the paper has finished moving — straight through your ticket.
Feed · Feed Where · Feed Distance How much paper is pushed out at the end, so the ticket clears the tear bar and the writing isn't still inside the machine. About 30 mm is right.
Orientation · Scaling · Fit to page Leave as Portrait and 100%. Anything that “fits” the ticket to a page is shrinking your ticket for no reason.
Density · Darkness · Print quality How hard the head burns the paper. Only worth touching if your tickets are faint — turning it up shortens the printer's life a little, so try a fresh roll first.

The Chrome settings in your print-station file

SettingIn plain words
--kioskFull screen, no address bar, no tabs — nobody can wander off to another site on the printing computer.
--kiosk-printingPrint with no dialog. Without it, every ticket waits for someone to click “Print”.
--disable-background-timer-throttlingChrome slows down a window that isn't in front. This stops it.
--disable-backgrounding-occluded-windowsThe important one. Chrome treats a window another window covers as if it were closed — this is why “opening another app killed printing”.
--disable-renderer-backgroundingSame idea one layer deeper: don't put the page itself to sleep.
--disable-features=CalculateNativeWinOcclusionThe Windows version of the covered-window problem.
--user-data-dirIts own private Chrome profile: stays logged in, and your everyday browsing stays separate.
--no-first-run --no-default-browser-checkSkip the “make Chrome your default browser?” questions, which otherwise sit on screen waiting.
--autoplay-policy=no-user-gesture-requiredLets the new-order chime sound without someone tapping first.
caffeinate · powercfg · xsetKeep the computer and screen awake. A sleeping computer prints nothing — the most common cause of “it stopped overnight”.

13 · The daily routine

Opening

  • Switch the computer on. If your print-station file is in Startup / Login Items / autostart it opens itself; otherwise double-click it.
  • Check the paper roll. Press 🖨 Preview a sample KOT once if you want to be sure.
  • Check it says Printing right now: THIS screen, then leave the window alone — other apps on top of it are fine.

During service

  • Paper out, jam, half a ticket → tap 🖨 and pick what happened. The manager is told at once.
  • Need a ticket again → the 🖨 button on that ticket. It comes out marked as a duplicate, on purpose.

Closing

  • Close the print window (⌘Q / Alt+F4). Nothing is lost if an order arrives after that — its ticket prints when you open again.
  • Signing out is under ☰ → Settings → Sign out on the kitchen screen.
