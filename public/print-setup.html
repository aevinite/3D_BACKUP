Kitchen printer — the complete setup guide

Everything needed to make kitchen tickets print by themselves — Windows, Mac, Linux or a Raspberry Pi — every step, every click, and the exact code to paste. Written for someone who has never set up a printer before. Your site is this site; every command below already uses it.

1 · Start here — the short version

  1. Plug the thermal printer into one computer and make it that computer's default printer.
  2. Pick your computer’s menu — ① Windows, ② Mac or ③ Linux / Raspberry Pi — and follow it once. Each menu walks you through making one small file yourself: open the text editor, press Copy on the code, paste it, save it with the exact name. There is nothing to download, and that is deliberate — a downloaded script is blocked by macOS (“Apple could not verify…”) and warned about by Windows, while a file you typed yourself simply opens.
  3. Ask us to switch printing on for the restaurant, and to say whether tickets print on the kitchen screen or the counter screen. (the switches)
  4. On that computer, say “print here” — kitchen screen: ☰ → Settings → 🖨 Printing; counter screen: Settings → Printing, or the strip that appears above the Tables grid.
  5. Send one order. A ticket should come out in a few seconds.
  6. Now minimise that window and send another. It must still print. That second ticket is the whole point of this setup. (the test)
In simple words: plug the printer in, open one special window on that computer, tell the app that this screen is the printer, then check it still prints when the window is hidden.

2 · Why printing used to stop (worth 60 seconds)

Kitchen tickets used to be printed by whichever screen happened to notice a new order. That only works while that screen is the window you are looking at. Minimise it — or simply open any other app on top of it — and the browser put it to sleep, so printing stopped completely, with nothing anywhere saying so.

Now the order itself leaves a “print me” job on our server. One screen is the printer; it takes each job, prints it, and tells the server it is done. If no screen takes it, the job waits — it can no longer be lost — and after 90 seconds the manager's Tables screen shows a warning with a 🖨 Print here instead button.

What this means for you: the printing window can be minimised, covered, or on another desktop, and tickets still come out. If the computer is off, the tickets are waiting the moment it comes back on.

The little file you make in your own menu below is the second half: it opens Chrome with the specific settings that stop it dozing off behind other windows, and keeps the computer itself awake.

The computer

Any Windows PC, Mac, Linux box or Raspberry Pi already there is fine — it does not need to be fast. It needs three things: it stays on during service, it is on the internet, and the printer is plugged into it (or reachable on the same network).

Paper

80mm thermal rolls — keep two spare. Thermal paper has no ink: if nothing prints, the roll is finished or in upside down.

4 · ① Windows — every step Windows 10 / 11

Nothing to download. You will type (paste) one small file yourself in Notepad. Windows never shows the “Windows protected your PC” warning for a file you made on your own computer — that warning only ever appears on files that came off the internet.

4.1 · Install the printer and make it the default

  1. Plug it in. Windows usually finds it. If not, install the driver from the CD or the maker's site (search the exact model, e.g. “XP-80C driver”).
  2. Settings → Bluetooth & devices → Printers & scanners — your printer should be listed. Click it → Print test page. If Windows can't print, the app certainly can't, so fix this first.
  3. Set as default: same screen → Set as default. Then turn OFF “Let Windows manage my default printer” — otherwise Windows quietly switches the default to whatever was used last and tickets go to the wrong printer.
  4. Paper size: Printer properties → Preferences → Paper size → pick the 80 mm × receipt option (names vary: 80(72.1)mm × Receipt, 80mm × 297mm…). Never A4.
In simple words: make sure Windows itself can print a test page on the thermal printer, that this printer is the default one, and that the paper is set to the small receipt size — not A4.

4.2 · Make the print-station file — every click

This one file opens Chrome with the settings that make tickets print by themselves and stop the window dozing off when it is minimised or covered.

  1. Open Notepad. Press Start, type notepad, press Enter.
  2. Copy the code below. Press the Copy button in the top-right corner of the black box — don't retype it by hand, a single missing word stops the automatic printing.
  3. Paste it into Notepad — click inside the Notepad window and press Ctrl + V.
  4. File → Save As…
  5. Choose Desktop in the left-hand list, so the file is easy to find.
  6. Change “Save as type” from Text Documents (*.txt) to All Files (*.*). This step matters most. Skip it and Windows saves print-station.bat.txt, which does absolutely nothing when double-clicked — and nothing tells you why.
  7. Name it and save it. In File name type exactly print-station.bat, press Save, then close Notepad.
  8. Check the name. On the Desktop the file must read print-station.bat. If it reads print-station.bat.txt, right-click → Rename and remove the .txt. (If you can't see the ending: File Explorer → View → Show → File name extensions.)

The code — press Copy, then paste it into Notepad exactly as it is:

@echo off
set "URL=https://www.aevinite.shop/kitchen"
set "PROFILE=%LOCALAPPDATA%\AevidinePrintStation"

set "CHROME=%ProgramFiles%\Google\Chrome\Application\chrome.exe"
if not exist "%CHROME%" set "CHROME=%ProgramFiles(x86)%\Google\Chrome\Application\chrome.exe"
if not exist "%CHROME%" (
  echo Install Google Chrome first, then run this again.
  pause
  exit /b 1
)

powercfg /change standby-timeout-ac 0 >nul 2>&1
powercfg /change monitor-timeout-ac 0 >nul 2>&1

start "" "%CHROME%" --kiosk --kiosk-printing ^
 --user-data-dir="%PROFILE%" ^
 --disable-background-timer-throttling ^
 --disable-backgrounding-occluded-windows ^
 --disable-renderer-backgrounding ^
 --disable-features=CalculateNativeWinOcclusion ^
 --no-first-run --no-default-browser-check ^
 --autoplay-policy=no-user-gesture-required ^
 "%URL%"
The only line you may ever want to change is the second one — set "URL=…". It already says your own address, https://www.aevinite.shop. Keep /kitchen at the end for a screen in or near the kitchen, or change it to /manager for the counter screen. Nothing else in the file ever needs touching.

4.3 · Start it and log in — once

  1. Double-click print-station.bat on the Desktop. A black box flashes, then a Chrome window opens full-screen with no address bar. That full-screen window is normal: it is what stops anyone browsing on the printing computer.
  2. Log in with the kitchen (or manager) username and password. You only do this once — this window keeps its own separate Chrome profile, so it stays logged in for good and your normal Chrome is left completely untouched.
Nothing happens when you double-click? The file is almost certainly saved as print-station.bat.txt — go back to step 4.2.8.

4.4 · Tell the app that THIS screen is the printer

  1. Ask us to switch printing on for your restaurant, and to say whether tickets come out on the kitchen screen or the counter screen. That is one switch on our side (§8).
  2. On this computer: kitchen screen → ☰ → Settings → 🖨 Printing → Print here. Counter screen → Settings → Printing, or the strip that appears above the Tables grid.
  3. Send one order and watch a ticket come out. Then do the real test.

4.5 · Make it start by itself (strongly recommended)

  1. Right-click print-station.bat → Show more options → Create shortcut.
  2. Open the Startup folder. Press Win + R, type shell:startup, press Enter — a folder opens.
  3. Drag the shortcut into that folder.

From now on the print station opens whenever the PC starts — including after a power cut, before anyone has to remember.

To finish for the day: press Alt + F4 in the Chrome window.

5 · ② Mac — every step macOS

Nothing to download — on purpose. macOS blocks any script that came from the web: double-clicking one gives “Not Opened — Apple could not verify it is free of malware” with only Done or Move to Bin, and the old right-click → Open way out was removed in macOS Sequoia. Nothing is wrong with such a file — but a file you type on your own Mac never gets that flag in the first place, so it simply opens. Everything below is typed by you.

5.1 · Install the printer and make it the default

Most cheap 80mm printers have no macOS driver of their own. For the POS-80 / ZJ-80 family the open-source zj-58 driver works. Open Terminal (⌘ + Space, type terminal, Enter) and paste these four lines:

git clone https://github.com/klirichek/zj-58
cd zj-58 && make
sudo cp rastertozj /usr/libexec/cups/filter/
sudo cp zj80.ppd /Library/Printers/PPDs/Contents/Resources/

Then → System Settings → Printers & Scanners → Add Printer, pick the USB printer, choose the ZJ-80 driver, and name it plainly — Printer_POS_80. Finally set it as the Default printer on that same screen: silent printing always goes to the default.

Never let macOS pick “Generic PostScript Printer”. A thermal printer cannot read PostScript, and the first print comes out wrong for that reason alone. Choose the thermal driver for your model.

5.2 · The four paper settings that matter

lpadmin -p Printer_POS_80 \
  -o PageSize=X70MMY65MM \
  -o CutMedia=EndOfJob \
  -o FeedWhere=AfterJob \
  -o FeedDist=9feed30mm \
  -o OptionCutter=True
PageSize=X70MMY65MM
A short receipt page. Chrome flows a long ticket across several of these and never slices a line of text in half.
CutMedia=EndOfJob
Cut once, after the ticket. EndOfPage cuts mid-ticket, because the cut happens before the final paper feed.
FeedWhere / FeedDist
Feed the paper out after the job, so the ticket clears the tear bar.
OptionCutter=True
Only if your unit has a blade. If it doesn't, leave this out.
Never set a paper size in the app's print settings. A pinned or landscape-shaped page makes the printer turn the ticket sideways; a size that doesn't match the roll pushes the ticket to the bottom of an imaginary page — that is the 20 cm blank lead-in.

5.3 · The 30-second way — one line in Terminal, no file at all try this first

  1. Open Terminal. Press ⌘ + Space, type terminal, press Enter.
  2. Paste the command. Press Copy on the box below, click inside Terminal, press ⌘ + V, then Enter.
  3. Log in once in the Chrome window that opens.
caffeinate -dimsu "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \

Leave that Terminal window open — it is what keeps the Mac awake. Closing the Chrome window (⌘Q) ends it. Change /kitchen to /manager for a counter screen.

In simple words: this is the same thing as the file below, just run once by hand. Perfect for checking everything works today. Make the file (5.4) for every day after that, so nobody has to remember a command.

5.4 · The every-day way — make the file yourself, every click

  1. Open TextEdit. Press ⌘ + Space, type textedit, press Enter. Choose New Document if it asks.
  2. Format → Make Plain Text (or ⇧⌘T). This step matters most. TextEdit writes decorated “rich text” by default and a rich-text file will never run — it just opens in TextEdit again, and nothing tells you why.
  3. Copy the code below. Use its Copy button, click into TextEdit, press ⌘ + V.
  4. File → Save… Press ⌘ + Shift + D to jump to the Desktop, or pick Desktop in the sidebar.
  5. Name it and save it. In Save As type exactly print-station.command. If a box asks about the ending, choose Use .command. Then close TextEdit.
  6. Make it runnable. In Terminal, paste these two lines and press Enter: 
    chmod +x ~/Desktop/print-station.command
~/Desktop/print-station.command
    The first line gives the file permission to run; the second starts it right away.
  7. Log in once in the Chrome window that opens. It keeps its own Chrome profile, so it stays logged in and your normal Chrome is untouched.
  8. From now on, just double-click it. Because you typed this file yourself it carries no download flag, so macOS never shows the “could not verify” message for it.

The code — press Copy, then paste it into plain-text TextEdit:

#!/bin/zsh
URL="https://www.aevinite.shop/kitchen"
PROFILE="$HOME/.aevidine-print-station"
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"

if [ ! -x "$CHROME" ]; then
  echo "Install Google Chrome first, then run this again."
  read -r "?Press return to close…"
  exit 1
fi

"$CHROME" \
  --kiosk --kiosk-printing \
  --user-data-dir="$PROFILE" \
  --disable-background-timer-throttling \
  --disable-backgrounding-occluded-windows \
  --disable-renderer-backgrounding \
  --no-first-run --no-default-browser-check \
  --autoplay-policy=no-user-gesture-required \
  "$URL" &
CHROME_PID=$!
caffeinate -dimsu -w $CHROME_PID &
wait $CHROME_PID
The only line you may ever want to change is the second one — URL="…". It already says your own address, https://www.aevinite.shop; keep /kitchen for a kitchen screen or put /manager for the counter. Nothing else needs touching.

5.7 · Already got a downloaded starter file sitting in Downloads?

Older versions of this guide offered one to download, and that is the file that shows “Apple could not verify…” (a macOS protection called Gatekeeper). You don't need it — 5.4 above replaces it — but if you'd rather use it, either of these gets you past it:

bash ~/Downloads/print-station-mac.command
xattr -d com.apple.quarantine ~/Downloads/print-station-mac.command
chmod +x ~/Downloads/print-station-mac.command

The first runs the file's contents without “opening” it, which macOS allows. The second removes the came-from-the-web flag for good, so it double-clicks normally. (The third route is System Settings → Privacy & Security, scroll to the message naming the file, press Open Anyway.) Nothing above is needed for a file you typed yourself.

6 · ③ Linux & Raspberry Pi — every step Ubuntu · Debian · Raspberry Pi OS

The cheapest print station that nobody ever touches: a Raspberry Pi (₹4,000–5,000) behind the till, 3 watts, no fan to clog with kitchen grease, and it comes back by itself after a power cut.

Nothing to download here either. You type the file with nano, the plain text editor that is already on the machine.

6.1 · Install the printer (CUPS) and make it the default

sudo apt update && sudo apt install -y cups printer-driver-escpr
sudo usermod -aG lpadmin $USER
lpinfo -v

lpinfo -v prints the printer's address, e.g. usb://Zjiang/POS-80. Add it, make it the default, and test:

sudo lpadmin -p POS80 -E -v "usb://Zjiang/POS-80" -m raw
sudo lpoptions -d POS80
echo "hello" | lp -d POS80

-m raw is deliberate: an 80mm thermal printer speaks ESC/POS, and “raw” means CUPS passes the job through untouched — which is what Chrome's output needs. If your model has a proper PPD (Epson's escpr covers many), use that instead.

A network printer instead of USB (recommended on a Pi) — give it a fixed address in your router first, or it will move and printing will stop for no visible reason:

sudo lpadmin -p POS80 -E -v socket://192.168.1.50:9100 -m raw
sudo lpadmin -p POS80 -o PageSize=Custom.72x200mm -o fit-to-page=false

6.2 · Make the print-station file — every step

  1. Open a Terminal. Type nano ~/print-station.sh and press Enter — an empty editor fills the window.
  2. Copy the code below. Use its Copy button — never retype a command line by hand.
  3. Paste it into nano. Press Ctrl + Shift + V, or right-click → Paste.
  4. Save and leave. Press Ctrl + O then Enter to save; Ctrl + X to leave.
  5. Make it runnable and start it: 
    chmod +x ~/print-station.sh
~/print-station.sh
  6. Log in once in the Chrome/Chromium window that opens.
#!/bin/sh
URL="https://www.aevinite.shop/kitchen"
PROFILE="$HOME/.aevidine-print-station"

BROWSER=""
for b in chromium-browser chromium google-chrome google-chrome-stable; do
  command -v "$b" >/dev/null 2>&1 && { BROWSER="$b"; break; }
done
[ -z "$BROWSER" ] && { echo "Install Chromium:  sudo apt install -y chromium-browser"; exit 1; }

xset s off 2>/dev/null; xset -dpms 2>/dev/null; xset s noblank 2>/dev/null

exec "$BROWSER" \
  --kiosk --kiosk-printing \
  --user-data-dir="$PROFILE" \
  --disable-background-timer-throttling \
  --disable-backgrounding-occluded-windows \
  --disable-renderer-backgrounding \
  --no-first-run --no-default-browser-check \
  --autoplay-policy=no-user-gesture-required \
  "$URL"
The only line you may ever want to change is the second one — URL="…" — already your own address, https://www.aevinite.shop, plus /kitchen or /manager.

6.4 · Start on boot (what makes it maintenance-free)

mkdir -p ~/.config/autostart
cat > ~/.config/autostart/print-station.desktop <<EOF
[Desktop Entry]
Type=Application
Name=Aevidine print station
Exec=$HOME/print-station.sh
X-GNOME-Autostart-enabled=true

After a power cut the Pi boots, opens the window and prints again — with nobody touching it. That is the one thing a PC at the till never does.

9 · One printer at a time — and how to switch

Exactly one screen prints for a restaurant. The server enforces it, so two screens can never both print the same ticket — and every other screen can see which one holds it.

What you seeWhat it meansWhat to do
Printing right now: THIS screenThe paper is coming out here.Nothing. Leave the window open — minimised is fine.
Printing right now: Kitchen screen · Ramesh (on the counter screen) Another screen holds it. If the printer is actually where you are, press 🖨 Print here instead — one tap, and that screen stops printing immediately.
… (gone quiet)That screen hasn't been heard from for a few minutes — closed, asleep or unplugged.Nothing needed: any entitled screen may take over automatically, so printing resumes as soon as one is open. You can also take it now.
no screen yetNobody has volunteered.Press 🖨 Print on this screen on the computer with the printer.

Where each panel shows it

  • Kitchen screen — ☰ → Settings → 🖨 Printing (and the 🖨 button on the top bar shows the same three lines).
  • Counter / manager screen — Settings → Printing, and a strip above the Tables grid when another screen holds it.
  • Owner panel — Settings → Kitchen printing: one line per restaurant saying which screen is printing. No controls there — an owner is not standing at the printer.
Nothing is ever lost while you switch. A ticket stays in the queue until a screen prints it, so taking over mid-service simply moves where the paper appears.
In simple words: one screen is “the printer”. Any other screen tells you which one, and one tap moves it to you.

10 · The test that actually matters

  1. Send a real order from the waiter tablet or the guest menu to a test table. A ticket should come out within a few seconds.
  2. Now minimise the print window — or open any other app full screen on top of it. This is exactly what used to kill printing.
  3. Send a second order. It must print while the window is still hidden. That is the test.
  4. Close the print window completely and send a third. Nothing prints — correct. Re-open the print station: the missed ticket comes out straight away. Nothing was lost.
  5. Cancel your test orders (manager → the table → cancel) so they never reach a real bill.
In simple words: print one, hide the window and print another, then close everything and prove the missed ticket appears when you re-open. That covers every way it used to fail.

Testing without wasting paper

Install a PDF printer and make it the default while you test — every “print” becomes a file you can look at. Windows already has Microsoft Print to PDF; a Mac's print dialog has Save as PDF; on Linux sudo apt install printer-driver-cups-pdf. Set the real printer back as default when you are done.

11 · Every setting explained

SettingIn plain words
--kioskFull screen, no address bar, no tabs — nobody can wander off to another site on the printing computer.
--kiosk-printingPrint with no dialog. Without it, every ticket waits for someone to click “Print”.
--disable-background-timer-throttlingChrome slows down a window that isn't in front. This stops it.
--disable-backgrounding-occluded-windowsThe important one. Chrome treats a window another window covers as if it were closed — this is why “opening another app killed printing”.
--disable-renderer-backgroundingSame idea one layer deeper: don't put the page itself to sleep.
--disable-features=CalculateNativeWinOcclusionThe Windows version of the covered-window problem.
--user-data-dirIts own private Chrome profile: stays logged in, and your everyday browsing stays separate.
--no-first-run --no-default-browser-checkSkip the “make Chrome your default browser?” questions, which otherwise sit on screen waiting.
--autoplay-policy=no-user-gesture-requiredLets the new-order chime sound without someone tapping first.
caffeinate · powercfg · xsetKeep the computer and screen awake. A sleeping computer prints nothing — the most common cause of “it stopped overnight”.

13 · The daily routine

Opening

  • Switch the computer on. If your print-station file is in Startup / Login Items / autostart it opens itself; otherwise double-click it.
  • Check the paper roll. Press 🖨 Preview a sample KOT once if you want to be sure.
  • Check it says Printing right now: THIS screen, then leave the window alone — other apps on top of it are fine.

During service

  • Paper out, jam, half a ticket → tap 🖨 and pick what happened. The manager is told at once.
  • Need a ticket again → the 🖨 button on that ticket. It comes out marked as a duplicate, on purpose.

Closing

  • Close the print window (⌘Q / Alt+F4). Nothing is lost if an order arrives after that — its ticket prints when you open again.
  • Signing out is under ☰ → Settings → Sign out on the kitchen screen.
