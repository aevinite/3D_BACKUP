4 · Where should the Khata option live? — pick one

You asked where "pay later" should sit. Three honest options:

Option A · Table mark
Khata stays one of the 4 table marks (like the blue tile above). Waiters know from the START the party pays later.
Weak spot: many khata moments are decided only at the END, when the bill comes.
Option B · At bill time ★ my pick
NO khata table mark. The normal payment popup simply gets a 4th button: 📒 Collect later (see mockup below). Works for ANY table, decided in the moment — which is how khata really happens.
Weak spot: no early signal to waiters — but khata guests rarely need special treatment, just special billing.
Option C · Both
The bill-time button ALWAYS exists, plus an optional khata table mark for known regulars.
Weak spot: two ways to do one thing — more buttons, more staff confusion, more code to maintain.
